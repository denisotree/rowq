rowq

Query rows in tables, documents and databases — from the terminal or through an AI assistant.

Written in Rust, Apache-2.0, by one developer. Continues tuitab.

what it does

6 rows
#featuresdescriptions
formatsA fast, keyboard-driven viewer and editor for CSV, TSV, JSON, JSONL, YAML, TOML, Markdown, Parquet, Arrow, Excel, SQLite and DuckDB.
nested dataJSON, YAML and TOML open as a browsable tree and are edited in place.
databasesSQLite and DuckDB tables are edited and saved as one transaction, with the SQL shown first.
large filesThrough the MCP server, large CSV, Parquet, Arrow and JSONL files are streamed, not loaded whole.
analysisFilter, sort, group, pivot, join, compute columns with expressions and window functions, describe, chart.
mcp serverStarted with --mcp, an AI assistant sends operations and reads back computed numbers instead of estimating them. --mcp-write lets it change database rows, always as a plan shown before it runs.

install

cargo

cargo install rowq

homebrew

brew tap denisotree/rowq
brew install rowq

aur pre-built: rowq-bin

yay -S rowq

apt Debian 12+, Ubuntu 22.04+, amd64/arm64

curl -fsSL https://rowq.dev/apt/rowq.gpg \
  | sudo tee /usr/share/keyrings/rowq.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/rowq.gpg] https://rowq.dev/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/rowq.list
sudo apt update && sudo apt install rowq

Pre-built archives, with rowq alone: github.com/denisotree/rowq/releases

use with an ai assistant

claude code

claude mcp add -s user rowq -- rowq --mcp

json config Claude Desktop, Cursor, Zed…

{ "mcpServers": { "rowq": { "command": "/opt/homebrew/bin/rowq", "args": ["--mcp"] } } }

Use the full path: a desktop app does not start from your shell.

coming from tuitab

rowq continues tuitab, which stays at 0.11.1 and keeps working. The two install side by side; remove tuitab when you no longer need it.

cargo

cargo install rowq

homebrew own tap

brew install denisotree/rowq/rowq

aur

Install rowq or rowq-bin; tuitab can stay or go.

apt

Add the rowq repository and install rowq. The tuitab repository stays at 0.11.1; to remove it:

sudo rm /etc/apt/sources.list.d/tuitab.list /usr/share/keyrings/tuitab.gpg

mcp

claude mcp remove tuitab

Add rowq as above, with --mcp-write if you had it. Permission rules follow the server's name: mcp__tuitab__tuitab_query → mcp__rowq__rowq_query, mcp__tuitab → mcp__rowq. In a JSON config, add a rowq entry with the command rowq.
